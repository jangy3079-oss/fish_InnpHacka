# 시연 대본 (4분) — 화면 대조 반영본

이슈 #41. 장연수님의 #41 대본 댓글에서 **두 가지를 고친 정리본**이다: ① JimmyApron이 현재 시연 화면과 대조해 알려 준 4곳, ② "경보가 나지 않는다"처럼 헷갈리는 표현.
원본 대본의 질의응답 메모와 한계 답변은 #41 댓글에 그대로 있다. 이 문서는 시연 장면 표만 다룬다.

**용어:** 화면에 보이는 정상·주의·경고·위험은 **단계**, 어민에게 가는 문자는 **알림**이라고 말한다. "경보"라는 말은 쓰지 않는다. "거짓 경보"는 "잘못된 경고"로 말한다.

시연 패널(우하단 "시연 모드 열기") 맨 위의 **장면 버튼 8개**(정상, 사료 권고, 고수온 피신, 위험·손익, 태풍, 질병 의심, 기생충 의심, 탁도 상승)를 누르면 시나리오와 시각 t가 한 번에 맞춰진다.

| 시간 | 장면 버튼 (t) | 말할 내용 |
| --- | --- | --- |
| 0:00–0:15 | 정상 (t≈5) | "8월 통영 가두리를 8일치로 재현했습니다. 지금은 정상입니다." |
| 0:15–0:30 | 사료 권고 (t≈12) | "수온 23℃대. 먹이 반응만 줄었습니다. 아직 위험한 단계는 아니라서 **'정상'으로 두고** 사료만 줄이라고 안내합니다." |
| 0:30–1:05 | 고수온 피신 (t=20→26) | "25℃를 넘자 물고기가 찬 아래쪽으로 몰립니다. 평소의 약 1.5배가 모이고 활동은 약 30% 줄었습니다. **주의 → 경고 → 위험**, 원인은 '고수온 피신'입니다. 28℃ 주의보까지는 **아직 사흘이 안 남았습니다.**" |
| 1:05–1:35 | 위험·손익 (t=26) | "유지, 월하장 이동, 조기 출하, 긴급방류의 예상 손해를 비교합니다. 방류는 품종·크기·마릿수 요건을 자동으로 확인합니다. 결정은 어민이 합니다." (**손익 카드는 이 장면에서 설명한다**) |
| 1:35–2:00 | 태풍 (t≈35) | "태풍이 물을 섞었습니다. 층간 수온 차가 사라지고 어군이 흩어집니다. 원인이 **피난처 소실**로 바뀌고, 피할 곳이 없어 위험 단계를 유지합니다." (**이 장면에서는 추천 카드를 가리키지 않는다**: 카드가 월하장 이동 문구로 고정돼 있다) |
| 2:00–2:30 | 질병 의심 (t≈34) | "수온이 정상인 날입니다. 그런데 이상 지수가 며칠에 걸쳐 조금씩 오르고, 활동이 줄며 아래로 가라앉습니다. 원인은 '**질병 의심**'. 손익 대신 약 없이 하는 1차 조치 세 가지, 사료 공급 조절·밀도 조절·폐사체 수거를 보여 줍니다." |
| 2:30–3:00 | 기생충 의심 (t≈39) + 진단 요청 버튼 | "몸을 그물에 비비는 횟수가 평소의 **3배를 넘었습니다.** '**기생충 의심**'입니다. 병명을 단정하지 않고, 버튼 하나로 수산질병관리사에게 **진단 요청을 접수**합니다. 약품명은 내보내지 않습니다." (화면에는 비비기 배수가 표시되지 않는다. 시연에서는 실제로 접수하지 않는다고 표시됨) |
| 3:00–3:30 | 탁도 상승 (t≈24) | "물이 탁해 카메라는 이상해 보여도, 소나를 보면 물고기는 평소와 같습니다. 그래서 **'정상'으로 표시하고 잘못된 경고를 내지 않습니다.**" (화면에는 '정상, 39점, 원인 없음'이 보인다. 카메라 비중을 낮춘다는 설명은 말로만 한다) |
| 3:30–4:00 | 지자체 대시보드 | "지자체는 해역별 상태와 방류 수요를 봅니다. 개별 어가 손익은 보이지 않습니다. 이렇게 고수온부터 질병까지, 물고기가 먼저 알려 줍니다." |

## 바뀐 점 (원본 대비)

| 주의보까지 남은 시간 | 나흘 | 사흘이 안 남음 | t=26 기준 28℃ 주의보까지 약 2.8일. "나흘"은 t=20 때 값 |
