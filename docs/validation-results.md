# 검증 결과표 (VC-01~08)

SRS 7.1의 검증 기준을 실행하고 결과를 기록하는 표다. 이슈 #40.
**이 문서의 결과 칸은 모두 비어 있다.** 실행한 뒤 실제 값만 채우고, 실행하지 않은 항목은 "미실행"으로 둔다.

- 시나리오 파일: `scenarios/*.yaml` (재현을 위해 `seed` 고정, 같은 시작 시각에서 같은 결과)
- 설정 버전: 결과를 적을 때 `python -m common.config_loader`가 출력하는 `revision`을 함께 적는다
- 상태: ⬜ 미실행 · ✅ 통과 · ❌ 미달 · ➖ 보고용(기준 없음)

## 항목별 기록

### VC-01 탁도 구간 지표 안정성
- 시나리오: `turbidity_event`
- 방법: 카메라 단독 지표와 소나 융합 지표를 같은 구간(탁도 높음)에서 비교
- 기록: 변동 지표(예: 표준편차) 카메라 단독 ___ / 융합 ___
- 실행 방법·명령: ___

### VC-02 이상 구간 탐지 재현율
- 시나리오: `heatwave_typhoon`, `disease_suspect`, `parasite_suspect`, `feeding_drop`, `turbidity_event` (정답 구간은 각 시나리오 주석·이벤트 기준)
- 방법: 합성 시나리오의 정답 이상 구간 중 지수가 이상으로 판정한 비율
- 기록: 시나리오별 재현율 ___ / 평균 ___

## 한계 (결과와 함께 적는다)
- 결과는 시뮬레이터(합성 데이터) 기준이며 현장 검증이 아니다.
- 질병·기생충은 "의심"까지만 판정한다.
- 수과원 근거 자료의 수준은 `notify/docs/README.md`를 따른다.
