# 시연 화면 녹화 백업 (현장 네트워크 대비)

이슈 #42 / 근거: SRS C-07

시연은 백엔드 없이 프론트 목업 데이터로 돌아가므로 네트워크가 없어도 됩니다. 그래도 노트북·브라우저 문제에 대비해 **화면 녹화를 미리 만들어 둡니다.** 녹화 파일은 팀원이 만들고, 이 문서는 무엇을 어떤 순서로 찍을지 정합니다.

## 준비
1. `cd frontend && npm install && npm run dev`, 브라우저로 `http://localhost:5173`을 엽니다.
2. 브라우저 창 크기를 발표 화면과 같게 맞춥니다 (전체 화면 권장).
3. 녹화 도구(Windows는 `Win+G` 게임 바, macOS는 `Shift+Cmd+5` 등)로 화면을 녹화합니다.

## 찍을 순서 (4분 시연 대본과 맞춤)
시연 대본은 #41(발표 자료)을 따릅니다. 아래는 화면 기준 요약입니다.

| 순서 | 화면 | 조작 |
| --- | --- | --- |
| 1 | 어민 현황, 시나리오 "고수온·태풍" | 시연 모드에서 시나리오 선택, 정상 시점 |
| 2 | 어민 현황 | 슬라이더를 움직여 급이 반응 감소, 주의, 경고, 위험으로 변하는 모습 |
| 3 | 근거 그래프 | 층별 수온·중층 쏠림·활동량 그래프 확인 |
| 4 | 손익 비교 카드 | 대응 선택지별 예상 손익과 긴급방류 요건 확인 |
| 5 | 알림 화면 | 근거 수치가 든 알림 확인 |
| 6 | 지자체 대시보드 | 해역 스트레스 지도·방류 수요 확인 |
| 7 | (선택) 질병 의심 시나리오 | 약품 없이 1차 조치와 진단 요청 접수 문구 확인 |

슬라이더 위치(`t`)는 프론트의 시연 데이터 기준이므로, 녹화 전에 시나리오별로 화면이 의도한 단계(주의→위험)를 보이는지 한 번 확인합니다.

## 저장
- 파일 이름: `demo-YYYYMMDD.mp4` (여러 개면 시나리오 이름을 붙임)
- 저장소에는 올리지 않습니다 (용량). 팀 공유 드라이브와 발표 노트북 로컬 두 곳에 둡니다.
- AI Hub 이미지는 화면에 넣지 않습니다. 넣으려면 제공기관의 서면 확인이 필요합니다 (SBOM.md 4.1).

## 시연 직전 체크

- [ ] 시나리오 3개 이상이 슬라이더로 바뀐다
- [ ] 녹화 파일이 발표 노트북에서 재생된다
- [ ] "현장 검증 전, 합성 데이터" 한계 문구를 말할 준비가 됐다
