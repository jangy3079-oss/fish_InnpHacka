## 규칙별 근거 현황

| 주제 | 규칙 | 근거 상태 |
| --- | --- | --- |
| 적조 | R4 | ✅ 공식 매뉴얼 있음 |
| 고수온 (사료 감량·중단, 산소, 밀도) | R1, R2 | ⚠️ 적조 매뉴얼의 사료·산소·밀도 항목과 보도 기사뿐. **고수온 전용 수과원 원문은 못 찾음** |
| 저산소 | R3 | ⚠️ 적조 매뉴얼의 산소공급장치 가동, 보도 기사의 산소 장치 점검뿐. 저산소 전용 원문 없음 |
| 질병·기생충 | R5, R8 | ⚠️ 보도 기사 + 질병예방 자료 목록. 본문 수집 필요 |
| 작업 스트레스 | R6 | ❌ 근거 없음 ("스트레스와 면역과의 관계" 자료 수집 필요) |
| 섭식 저하 | R7 | ⚠️ 적조 매뉴얼의 포식량 50%는 적조 단계 기준. 섭식 저하 전용 근거 없음 |

## 사용 규칙
1. 알림 문구는 **✅ 문서의 표현 안에서만** 만든다. ⚠️ 문서는 보조 근거이며, 단독으로 수치 지시를 만들지 않는다.
2. 적조 외 규칙에 적조 매뉴얼 문구를 쓸 때는 근거 범위(적조 매뉴얼)를 `evidence`에 남긴다.
3. 약품명·투약량은 어떤 문서에서도 가져오지 않는다 (C-01).
4. 새 문서는 출처 URL, 확인일, 자료 종류(공식/보도), 원문 확인 여부를 맨 위에 적는다.
