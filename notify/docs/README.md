## 규칙별 근거 현황

| 주제 | 규칙 | 근거 상태 |
| --- | --- | --- |
| 적조 | R4 | ✅ 공식 매뉴얼 있음 |
| 고수온 (사료·산소·밀도) | R1, R2 | ⚠️ 병리연구과 자료에 "고수온기 사료 과잉 투여 금물", "고수온기 이동 자제", 수온·산소 관계는 있음. **수치 기준이 있는 고수온 전용 수과원 원문은 못 찾음** |
| 저산소 | R3 | ⚠️ 병리연구과 자료의 입올림 현상·산소 부족 영향, 적조 매뉴얼의 산소공급장치 가동. 저산소 전용 원문은 없음 |
| 질병 | R5 | ✅ 사료·밀도·폐사어 제거·진단 의뢰는 공식 자료에 있음 (대부분 2011년 기고글) |
| 기생충 | R8 | ⚠️ 공통 1차 조치는 R5와 같은 근거. 기생충 전용 대응은 "기생충성 질병" PDF 본문을 더 읽어야 함 |
| 작업 스트레스 | R6 | ⚠️ 이동·선별·운반 스트레스 설명은 있음. 회복 모니터링 요령은 없음 |
| 섭식 저하 | R7 | ⚠️ 포식량 70~80%는 있으나 "20% 감량"(UC-04)과 기준이 다름 |

## 사용 규칙
1. 알림 문구는 **✅ 문서의 표현 안에서만** 만든다. ⚠️ 문서는 보조 근거이며, 단독으로 수치 지시를 만들지 않는다.
2. 적조 외 규칙에 적조 매뉴얼 문구를 쓸 때는 근거 범위(적조 매뉴얼)를 `evidence`에 남긴다.
3. 약품명·투약량은 어떤 문서에서도 가져오지 않는다 (C-01).
4. 새 문서는 출처 URL, 확인일, 자료 종류(공식/보도), 원문 확인 여부를 맨 위에 적는다.
