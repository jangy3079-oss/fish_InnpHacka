# 원인별 현장 조치 문구 후보 (알림용)

이슈 #20, #34. 수과원 문서에 있는 표현 안에서만 만들었다 (SRS C-04). **후보**이며 최종 문구는 알림 생성(#34) 구현에서 정한다.
알림은 3문장 이내 (NFR-USE-01). 약품·투약 표현은 쓰지 않는다 (C-01). 수치는 원문에 있는 것만 쓰고, 지시형 수치("20% 감량")는 만들지 않는다.

근거 ID: **H** = 고수온 단계별 요령표 (`nifs_high_temp_stage_manual.md`), **R** = 적조 매뉴얼 (`nifs_red_tide_cage_manual.md`), **D4·D5·D8·D2** = `nifs_disease_rearing_management.md`, **P** = 기생충성 질병 (`nifs_parasitic_diseases.md`), **S1** = 스트레스와 면역 (`nifs_stress_immunity.md`).

## 이전 문구에서 구체적으로 바뀐 것
- R6: "스트레스 요인을 줄이세요"라는 추상 문구를 S1의 작업 방법(촘촘한 그물망, 물 밖에 드는 시간 최소화, 회복에 고농도 산소)으로 바꿨다.
- R5·R8: 격리, 기구 소독, 새 어류 입식 금지(S1)를 추가했다. 기구 소독은 `tool_disinfection`의 공식 근거도 된다.
- R7: 과식·절식 주의(S1 영양)를 덧붙였다. 수치는 쓰지 않는다.

## 쓰지 않는 것
- "20% 감량", "포식량 50%·70~80%", "황토 1ha당 2~4톤" 같은 수치 지시 (원문에 있어도 이 상황의 지시로 만들지 않는다)
- 약품·약욕·투약 표현, 질병 종류(연쇄구균 등)의 병명 단정

## 결정이 필요한 것
1. R3 알림에 "용존산소 5 mg/L 이상"을 쓸지 (S1에 근거가 있으나 `do_low_mg_l`은 4.0 가정값과 다름)
2. R4를 특보 단계별로 나눠 쓸지 (#34 댓글 참고)
3. `tool_disinfection`을 official로 올릴지 (S1에서 기구 소독 근거가 확인됨)
