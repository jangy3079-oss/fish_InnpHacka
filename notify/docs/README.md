## 규칙별 근거 현황

| 주제 | 규칙 | 근거 상태 |
| --- | --- | --- |
| 적조 | R4 | ✅ 공식 매뉴얼 있음 |
| 고수온 (사료·산소·밀도) | R1, R2 | ✅ 단계별 요령 표가 있음 (경계 27~28℃부터 사료 공급 중단, 산소 장비 총력 가동, 차광막·그물 침하). 2018년 자료라 현행 특보 기준과 대조 필요 |
| 저산소 | R3 | ⚠️ 병리연구과 자료의 입올림 현상·산소 부족 영향, 적조 매뉴얼의 산소공급장치 가동. 저산소 전용 원문은 없음 |
| 질병 | R5 | ✅ 사료·밀도·폐사어 제거·진단 의뢰는 공식 자료에 있음 (대부분 2011년 기고글) |
| 기생충 | R8 | ⚠️ 증상·발생 조건·예방은 공식 PDF에 있음 (조피볼락 아가미흡충증은 9~10월 가두리망 청소). 단 "몸 비비기" 서술은 없어 알림은 "기생충성 질병 의심"까지만 |
| 작업 스트레스 | R6 | ⚠️ 이동·선별·운반 스트레스 설명은 있음. 회복 모니터링 요령은 없음 |
| 섭식 저하 | R7 | ⚠️ 포식량 70~80%(질병 맥락), 포식량 50%(적조 맥락)는 있으나 고수온·섭식 저하용 감량 수치는 **공식 자료에서 찾지 못함** (2026-11-27 확인). 알림은 "사료 투입량을 줄이세요"(수과원 표현)로 쓰고, 경계 단계(27~28℃)부터는 "사료 공급 중단". "20% 감량"(UC-04)은 시뮬레이터·평가용 가정값. 학술 논문·언론의 급이율 수치는 공식 관리요령이 아니라 쓰지 않음 (C-04). 수치가 필요하면 수과원 사료연구센터(054-230-3620)나 수산기술센터에 서면 문의 |

## 사용 규칙
1. 알림 문구는 **✅ 문서의 표현 안에서만** 만든다. ⚠️ 문서는 보조 근거이며, 단독으로 수치 지시를 만들지 않는다.
2. 적조 외 규칙에 적조 매뉴얼 문구를 쓸 때는 근거 범위(적조 매뉴얼)를 `evidence`에 남긴다.
3. 약품명·투약량은 어떤 문서에서도 가져오지 않는다 (C-01).
4. 새 문서는 출처 URL, 확인일, 자료 종류(공식/보도), 원문 확인 여부를 맨 위에 적는다.
